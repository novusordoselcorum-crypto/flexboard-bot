# FlexBoard Bot

Telegram бот для уведомлений FlexBoard.

## Деплой на Railway

1. Создай новый репозиторий на GitHub
2. Закинь все файлы туда
3. В Railway: New Project → Deploy from GitHub → выбери репо
4. В Railway добавь переменные окружения (Variables):
   - BOT_TOKEN
   - SB_URL
   - SB_KEY
   - APP_URL

## Что делает бот

- /start — приветствие + кнопка открытия приложения
- Каждые 5 минут — проверяет выполненные задачи, шлёт уведомление фаундерам и инвесторам
- В 09:00 — напоминания о дедлайнах на сегодня и завтра
- В 20:00 — ежедневный отчёт с прогрессом по всем проектам
